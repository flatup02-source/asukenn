# HUMAN_APPROVAL_RULES

人間の承認なしにAIが実行してはいけないことを定義する。

## 必ず人間承認が必要（送信・実行前に止める）
- お客様へのメッセージ送信（LINE・メール・SNS含む）
- 体験予約の確定
- 料金・キャンペーンの変更や案内の断定
- 返金に関する判断・回答
- 退会・休会に関する判断・回答
- 怪我・体調・安全に関する判断・回答
- 未成年（キッズ）対応に関する判断
- クレーム対応
- 記録（ファイル）の削除
- 顧客データのエクスポート・外部送信
- 破壊的なコマンドの実行
- 本番環境の設定変更

## AIが承認なしでやってよいこと
- 質問を作る・聞く
- 回答を整理する
- Markdownログを作成・保存する
- フォロー候補・タスクを抽出する
- 返信案・文面案を「下書き」として作る（送信はしない）
- 要確認項目を明示する

## 承認フロー
1. AIが下書き・提案・整理を作る
2. 人間確認が必要な項目を明示する
3. 人間が内容を確認する
4. 人間が承認・修正・却下する
5. 送信・実行は人間が行う

## 迷ったときの原則
判断に迷ったら実行しない。必ず人間に確認する。
「送らない・決めない・止めて聞く」を選ぶ。
