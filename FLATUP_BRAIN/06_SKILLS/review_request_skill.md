# review_request_skill

## Purpose
Detect good timing to ask for a Google review.

## Good Candidates
- 体験後に喜んでいた人
- 入会直後で満足度が高い人
- 子どもが楽しそうだった保護者
- ダイエットや運動不足解消で前向きな反応があった人
- イベント後に感謝してくれた人

## Avoid
- クレーム中
- 返信が止まっている人
- 料金で迷っている人
- 退会・休会検討中の人
- 怪我や不安がある人

## Output
- 候補者
- 理由
- 依頼タイミング
- LINE文面案
- 人間確認
