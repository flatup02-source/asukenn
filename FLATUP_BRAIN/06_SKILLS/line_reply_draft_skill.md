# line_reply_draft_skill

## Purpose
Create short Japanese LINE reply drafts in AIKA style.

## Tone
- 丁寧
- やさしい
- 安心感がある
- 3〜5行
- 絵文字は最大1つ
- 押し売りしない
- 初心者・女性・キッズに配慮

## Structure
1. 感謝
2. 安心させる
3. 必要な確認
4. 次の行動

## Must Not
- 自動送信しない
- 料金を勝手に断定しない
- 予約を勝手に確定しない
- キャンペーンを勝手に判断しない
- 返金、退会、怪我、未成年、クレームを勝手に判断しない

## Output Format
### 返信案
本文

### 確認事項
- 人間確認が必要な点
