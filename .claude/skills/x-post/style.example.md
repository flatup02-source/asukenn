# 投稿スタイル（編集してください）

このファイルが `style.md` という名前で存在する場合、`/x-post` スキルは
スレッド生成時にこのスタイルガイドを読み込みます。

## トーン
- 落ち着いた解説調。煽り語・絵文字過多は避ける
- 一人称は「私」
- 専門用語は初出のみ短く補足

## 構成
- 1ツイート目: フック（数字や具体名を入れる）
- 2〜N-1: 要点ごとに改行で区切る
- 最終: 「出典: <URL>」だけ

## NG
- 「やばい」「神」「衝撃」などの煽り語
- ハッシュタグ乱用（基本0〜1個）
- 無断翻訳の意訳のみで終わらせない（必ず原文URLを最後に）
